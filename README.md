# MBCS - 银行核心业务系统

基于 Spring Boot 2.7 + MyBatis-Plus + Vue 3 的银行核心账务系统雏形，涵盖对公存款、账户管理、交易处理等核心银行业务领域。

## ✨ 功能模块

| 模块 | 功能 |
|------|------|
| 🏢 **机构管理** | 银行机构层级管理 |
| 👤 **柜员管理** | 柜员账户、权限分配 |
| 👥 **客户管理** | 客户信息维护 |
| 💳 **账户业务** | 开销户（个人/对公/负债账户）、账户查询、子账户管理 |
| 🔒 **账户限制** | 账户冻结/解冻、限制状态总览 |
| 💰 **交易管理** | 存款/取款交易、交易冲正、交易流水查询 |
| 🏭 **产品工厂** | 产品参数化配置（kdpf_* 参数表体系）|
| 📜 **大额存单** | 产品期次发行、客户认购、提前/到期兑付、存单查询、行内转让 |
| ⚙️ **批量处理** | 结息批量、自动兑付批量 |
| 📋 **通知存款** | 通知存款开户、支取预约、到期支取 |

## 🏗️ 技术栈

| 分类 | 技术 |
|------|------|
| **后端框架** | Spring Boot 2.7.18, Spring Cloud Alibaba 2021.0.6.1 |
| **ORM** | MyBatis-Plus 3.5.3 |
| **数据库** | MySQL / Oracle / PostgreSQL / H2 |
| **中间件** | Nacos/ESB, Redis, Kafka, Sentinel |
| **安全** | Spring Security |
| **前端** | Vue 3 + Element Plus + Pinia + Vue Router |
| **构建** | Maven (后端), Vite (前端) |

## 📁 项目结构

`
MBCS/
├── bank-core/               # 后端 (Java / Maven)
│   ├── bank-common/         # 公共组件（工具类、异常、枚举、统一返回）
│   ├── bank-customer/       # 客户管理模块
│   ├── bank-liability/      # 负债业务模块（账户、交易、产品工厂）
│   ├── bank-teller/         # 柜员与机构管理模块
│   ├── bank-server/         # 聚合服务（单体应用入口）
│   └── db/                  # 数据库初始化脚本
├── bank-web/                # 前端 (Vue 3)
│   └── src/
│       ├── views/           # 页面组件
│       ├── router/          # 路由配置
│       ├── stores/          # 状态管理(Pinia)
│       └── api/             # API 接口层
└── bank-maven/              # Maven 仓库配置
`

## 📚 领域知识

参考 mbcs skill，涵盖存款业务领域核心知识：

- **产品工厂**：产品参数配置体系，kdpf_chpshx / kdpf_cpdxkz 等 8 张核心参数表
- **账户生命周期**：开户 → 未启用 → 正常 → 久悬/冻结/停用 → 销户
- **开销户流程**：个人开户 / 对公开户 / 负债账户开户 / 销户
- **账户限制**：冻结、解冻、停用、司法冻结、质押
- **交易处理**：存款、取款、冲正、会计分录
- **利率利息**：年/月/日利率，单利/复利/分段计息，计提与结息
- **大额存单**：产品期次发行 → 客户认购 → 利息试算 → 提前/到期兑付 → 行内转让
- **批量作业**：结息批量、自动兑付批量
- **通知存款**：1天/7天通知存款开户 → 支取预约 → 到期支取本息
- **大额存单转让**：行内全额转让、系统/客户定价、转让冲正
